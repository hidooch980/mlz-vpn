# MLZ VPN

**MLZ VPN** یک کلاینت VPN و پراکسی متن‌باز (تحت مجوز MIT)، رایگان، چند‌هسته‌ای و کاملاً بدون تنظیمات دستی برای **Windows** و **Android** است (با معماری آماده برای توسعه به Linux، macOS و iOS در فازهای بعدی).

## فلسفه پروژه
- **صفر تنظیمات فنی برای کاربر:** بدون نیاز به وارد کردن لینک سابسکریپشن، انتخاب دستی هسته یا افزودن کانفیگ دستی.
- **معماری ترکیبی هوشمند:** `sing-box` به‌عنوان هسته اصلی (صاحب `TUN`، `Split-DNS` و مسیریابی)، همراه با `Xray-core` به‌عنوان هسته مکمل تخصصی و پکیج کامل سایدکارهای مدولار (**All-In Sidecars**).
- **مسیریابی هوشمند سایت‌های ایرانی:** دسترسی مستقیم و بدون افت سرعت به دامنه‌های `.ir` و سرویس‌های بانکی/داخلی.
- **به‌روزرسانی ۵ دقیقه‌ای امضاشده:** فید سرورهای تاییدشده با امضای دیجیتال `Ed25519` از طریق GitHub/CDN Mirror و بذر آفلاین داخلی.
- **به‌روزرسانی مستقیم از داخل برنامه:** اعلام نسخهٔ جدید، دانلود امن با بررسی SHA-256 و نصب APK/Setup بدون مراجعه به GitHub؛ مانیفست با `Ed25519` امضا می‌شود.
- **عیب‌یابی هوشمند و خودترمیمی:** تشخیص خودکار محدودیت اپراتور (مثل قطع UDP یا اختلال SNI)، سوییچ خودکار به پروتکل/سایدکار مناسب و نمایش پیام ساده فارسی.

## وضعیت فعلی پروژه
- **ویندوز:** کامل و قابل انتشار؛ موتور Go، رابط Flutter، هسته‌های همراه، مسیریابی ایران، فید امضاشده، نصب‌کنندهٔ NSIS و انتشار GitHub Actions پیاده‌سازی شده است. به‌روزرسانی داخل برنامه، فایل `setup.exe` را دانلود و اجرا می‌کند.
- **اندروید:** رابط Flutter و VpnService کامل است و داده‌مسیر واقعی از طریق `libbox` (هسته sing-box) داخل AAR اجرا می‌شود. APKهای release با کلید اختصاصی امضا می‌شوند و نسخهٔ x86_64 روی شبیه‌ساز تست شده است. در نبود AAR برنامه به‌صورت امن اتصال را رد می‌کند.
- **تست اندروید:** اتصال TUN، عبور ترافیک واقعی، تست IP و اتصال مجدد پس از تغییر شبکه روی شبیه‌ساز x86_64 بررسی شده است. Xray روی اندروید به‌صورت آگاهانه پشتیبانی نمی‌شود؛ فقط sing-box/libbox.

## ساخت سریع
پیش‌نیازها: Go 1.25.5+، Flutter 3.50+، Android SDK/NDK 28 برای اندروید.

```powershell
# ویندوز
cd engine; go build -o bin/mlz-engine.exe ./cmd/mlz-engine
cd ..\app; flutter pub get; flutter build windows --release
# نصب‌کننده (پس از قرار دادن cores و rules در Release)
cd ..; powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_windows_installer.ps1
```

برای ساخت AAR و APK اندروید و همچنین کلیدهای امضا و فید، به [راهنمای انتشار](./docs/BUILD_AND_RELEASE.md) مراجعه کنید.

## امنیت
- فید سرورها و مانیفست به‌روزرسانی با امضای `Ed25519` بررسی می‌شوند؛ فید بدون امضا یا با امضای نامعتبر رد می‌شود.
- IPC فقط روی `127.0.0.1` با توکن اجباری و بدنه محدود JSON کار می‌کند.
- دانلود به‌روزرسانی فقط HTTPS و فقط از میزبان‌های مجاز است؛ مسیرهای داخلی/loopback مسدود هستند.
- هر بستهٔ به‌روزرسانی پیش از نصب با SHA-256 مانیفست امضاشده مقایسه می‌شود؛ در اندروید نصب از طریق `FileProvider` و با تأیید صریح کاربر انجام می‌شود.
- کلید خصوصی فید فقط در GitHub Actions (`MLZ_FEED_PRIVKEY`) نگهداری می‌شود و هرگز در مخزن قرار نمی‌گیرد.
